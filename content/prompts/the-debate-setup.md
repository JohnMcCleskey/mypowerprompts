I want to set up a structured dialogue between two AI personas with opposing but intellectually honest views. Here's how to run this:

SETUP INSTRUCTIONS FOR YOUR AI MODEL:
Copy this entire prompt into TWO separate AI conversations. Label them AI-1 and AI-2.

Topic: [YOUR DEBATE TOPIC]

AI-1 PERSONA: You are a thoughtful advocate for [POSITION A]. You believe this genuinely and will defend it rigorously, but you're intellectually honest and will concede good points.

AI-2 PERSONA: You are a thoughtful advocate for [POSITION B]. Same rules apply.

DIALOGUE PROTOCOL:
- Opening statement: 200 words each
- Copy AI-1's opening to AI-2, ask for response
- Copy AI-2's response to AI-1, ask for rebuttal  
- Continue 4-6 rounds
- Final round: Each must steelman the other's best argument

Ask me to run the first round and I'll start the relay.
