Every important AI conversation should start with a "collaboration contract" — explicit rules about how we'll work together. This eliminates the back-and-forth and sets up success from message one.

My typical use cases:
[DESCRIBE HOW YOU USUALLY USE AI]

Create my universal collaboration contract:

1. THE OPERATING SYSTEM: A paragraph I can paste at the start of any important conversation that establishes:
   - My communication preferences
   - Quality expectations
   - How I want uncertainty handled
   - Format defaults
   - When to ask for clarification vs. make assumptions

2. THE DOMAIN-SPECIFIC CONTRACTS: Customized versions for:
   - Writing tasks
   - Analysis tasks
   - Creative tasks
   - Technical tasks
   - Decision-making tasks

3. THE FEEDBACK LANGUAGE: Pre-agreed phrases that efficiently redirect the AI:
   - "Go deeper" means: [define]
   - "Too generic" means: [define]
   - "More like..." means: [define]
   - "Reset" means: [define]

4. THE META-RULES: Rules about rules — when to break the contract, when to update it

Make the universal contract under 150 words — short enough to paste every time without thinking about it.
