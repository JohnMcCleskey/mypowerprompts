I want to design an AI agent — a system that can handle a complex task with multiple steps, make decisions along the way, and produce a final result with minimal human intervention.

The task I want to automate: [DESCRIBE THE END-TO-END PROCESS]
Current human steps involved: [LIST THE STEPS A PERSON CURRENTLY DOES]
Acceptable error rate: [HOW PERFECT DOES IT NEED TO BE?]

Design the agent:
1. THE GOAL SPECIFICATION: Define the agent's objective so clearly that success/failure is unambiguous
2. THE DECISION TREE: Map every decision point the agent will face, with rules for each
3. THE TOOL KIT: What external tools/APIs does the agent need? (search, calculator, database, etc.)
4. THE MEMORY SYSTEM: What does the agent need to remember across steps? How is it stored?
5. THE GUARDRAILS: Where must the agent stop and ask a human? What actions are off-limits?
6. THE ERROR RECOVERY: When something goes wrong mid-process, what does the agent do?
7. THE OUTPUT SPEC: What does the final deliverable look like?
8. THE MONITORING DASHBOARD: How do I track what the agent is doing and catch problems early?

Present this as a technical specification document that a developer could implement.
