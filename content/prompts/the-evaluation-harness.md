I need to evaluate AI output systematically, not just by gut feel. Help me build an evaluation harness — a repeatable system for grading quality.

What I'm evaluating: [THE TYPE OF AI OUTPUT — writing, code, analysis, summaries, etc.]
Who the output is for: [THE AUDIENCE]
What makes output "great" in my context: [YOUR QUALITY STANDARD]

Build the evaluation harness:
1. THE RUBRIC: A 1-5 scoring system across these dimensions:
   - Accuracy (factual correctness)
   - Relevance (actually answers the question)
   - Completeness (nothing important is missing)
   - Clarity (easy to understand)
   - Actionability (can I use this immediately?)
   Score each dimension with specific criteria for each level.

2. THE GOLDEN SET: Create 3 example outputs rated as "5/5" — these become my reference standard

3. THE FAILURE EXAMPLES: Create 3 example outputs rated as "2/5" — so I know what "bad" looks like

4. THE SPEED TEST: How to evaluate quality in under 30 seconds (the quick rubric)

5. THE IMPROVEMENT LOOP: When output scores below 4, the exact prompt to send to improve it

6. THE TRACKING TEMPLATE: A simple spreadsheet structure to track quality over time and spot trends

This should make quality evaluation as fast and objective as possible.
