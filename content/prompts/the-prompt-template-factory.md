I want to build a personal library of reusable prompt templates — prompts I'll use repeatedly with different inputs. The best templates save hours over their lifetime.

My most common AI tasks:
[LIST 5 THINGS YOU FREQUENTLY USE AI FOR]

For each task, build a production-grade template:
1. THE TEMPLATE: Complete prompt with clearly marked [VARIABLE] slots
2. THE VARIABLES: List each variable with its type, example values, and what makes a good vs. bad input
3. THE PREAMBLE: A context-setting paragraph that stays the same every time
4. THE QUALITY CRITERIA: What "good output" looks like for this template (embedded in the prompt)
5. THE OUTPUT FORMAT: Exactly how the response should be structured
6. THE VERSIONING NOTE: What to adjust if the template isn't performing well

Then create a MASTER TEMPLATE — a template for creating new templates — that I can use whenever I discover a new repeating task.

Design each template to work across different AI models (GPT, Claude, Gemini) without modification.
