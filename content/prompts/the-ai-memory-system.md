AI has no memory between conversations. Every session starts from zero. I want to build a personal memory system that lets me carry context, preferences, and past decisions across all my AI interactions.

How I use AI: [YOUR TYPICAL AI USAGE PATTERNS]
Information that should persist: [WHAT THE AI SHOULD ALWAYS KNOW ABOUT YOU]

Design my memory system:
1. THE PERSONAL CONTEXT FILE: A structured document I paste at the start of every important conversation. Include:
   - My role and domain
   - My communication preferences
   - Past decisions and their rationale
   - Recurring tasks and their requirements
   - My vocabulary and jargon preferences

2. THE UPDATE PROTOCOL: A prompt I use at the end of important conversations to extract what should be added to my context file

3. THE CATEGORY SYSTEM: Organize memory into types — preferences, decisions, facts, style, history

4. THE COMPRESSION TECHNIQUE: How to keep the context file under 500 words while preserving maximum value

5. THE VERSION CONTROL: How to update the file without losing important historical context

6. THE STARTER TEMPLATE: A ready-to-use context file template I can fill in right now

The goal: every AI conversation should feel like talking to someone who already knows me.
