I want to objectively compare different AI models for my use case. Help me set up a rigorous comparison framework.

My primary use case: [WHAT YOU USE AI FOR]
Models I have access to: [GPT-4, Claude, Gemini, etc.]
What matters most to me: [ACCURACY / SPEED / CREATIVITY / COST / FORMAT CONTROL]

Build my comparison framework:
1. TEST CASES: Design 5 test prompts that represent my real-world usage, ranging from simple to complex
2. SCORING RUBRIC: For each test case, define exactly what "excellent," "good," "acceptable," and "poor" look like
3. THE BLIND TEST: How to run the comparison without bias (you tend to prefer whichever you test first)
4. DIMENSION SCORES: Rate each dimension separately — accuracy, creativity, instruction-following, speed, verbosity
5. THE EDGE CASE BATTERY: 3 prompts specifically designed to reveal each model's weaknesses
6. COST ANALYSIS: How to calculate actual cost-per-quality-output for each model
7. THE DECISION MATRIX: A weighted scoring system based on what matters most to me
8. THE RECOMMENDATION: Based on this framework, which model should be my default, and when should I switch?

Design this so I can re-run it whenever a new model drops.
