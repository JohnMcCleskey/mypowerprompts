You are my personal strategist. Help me build a focused game plan for this week — not a task list, but a real strategy.

My #1 goal this week: [YOUR MAIN GOAL]
My current projects: [LIST ACTIVE PROJECTS]
Meetings/commitments already locked in: [YOUR SCHEDULE]
Energy pattern (when I'm sharpest): [MORNING / AFTERNOON / EVENING]
What derailed me last week: [WHAT WENT WRONG]

Deliver:
1. WEEKLY THEME — A single sentence that defines what this week is about
2. THE NON-NEGOTIABLES — 3 outcomes I must hit for the week to be a win
3. DAILY POWER HOUR — Best time block per day for deep work given my energy pattern
4. PRE-MORTEMS — The 2 most likely things that will derail this week, and how to prevent them
5. DAILY CHECK-IN QUESTION — One question I ask myself each morning to stay on strategy
6. FRIDAY WIN METRIC — How I'll know on Friday that this week was a success
