I struggle with delegation — either I don't delegate enough, or I delegate poorly and end up redoing the work. Help me create a bulletproof delegation package for this task.

The task I want to delegate:
[DESCRIBE THE TASK IN DETAIL]

Create a complete delegation package:
1. THE ONE-SENTENCE BRIEF: What does "done" look like? (so clear a stranger could verify it)
2. THE CONTEXT DUMP: What does the person need to know to do this well?
3. THE PROCESS: Step-by-step instructions, assuming competence but not mind-reading
4. THE GUARDRAILS: What are the boundaries? What should they NOT do?
5. THE CHECK-IN PROTOCOL: When should they update me? What decisions can they make alone?
6. THE QUALITY CRITERIA: How will we both know if the output is good enough?
7. THE ESCALATION TRIGGER: What situations mean "stop and ask me"?
8. THE HANDOFF MESSAGE: Write the exact message I should send to hand this off (copy-paste ready)

Design this so I never have to think about this task again.
