My prompt isn't working as well as I want it to. Instead of rewriting from scratch, let's diagnose and fix it systematically — like debugging code.

My current prompt:
[PASTE YOUR UNDERPERFORMING PROMPT]

The output I'm getting:
[DESCRIBE OR PASTE WHAT THE AI PRODUCES]

What I actually want:
[DESCRIBE YOUR IDEAL OUTPUT]

Run the diagnostic:
1. THE CLARITY SCAN: Is every instruction unambiguous? Flag anything the model could misinterpret.
2. THE COMPLETENESS CHECK: What context is missing that the model needs to do this well?
3. THE CONFLICT DETECTOR: Are any of my instructions contradicting each other?
4. THE PRIORITY ANALYSIS: Which instructions is the model likely prioritizing? Is that the right order?
5. THE FORMAT DIAGNOSIS: Is the output format issue or a content issue? (Most people confuse these)
6. THE REWRITE: Produce an improved version with annotations explaining each change
7. THE A/B TEST: Design a simple test to verify the new version actually performs better
8. THE ROOT CAUSE: What was the single most impactful problem? (So I learn for next time)

Show me the before/after side by side so I can internalize the improvement patterns.
