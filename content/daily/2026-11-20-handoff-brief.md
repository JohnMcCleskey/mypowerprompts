title: The Handoff Brief
slug: handoff-brief
tags: [computer use, ops efficiency, delegation]
what_it_does: Turns a chore you repeat every week into a clear, step-by-step brief that an AI agent able to use your computer or browser can follow, with approval stops before anything risky.
prompt: |
  Interview me, one question at a time, about a task I repeat every week: where it starts, which apps, files and websites it touches, what a finished result looks like, and what usually goes wrong. Then write step-by-step instructions a computer-use agent can follow, naming each app, file and site, explaining how to handle anything unexpected, and pausing for my OK before it sends, pays for, submits or deletes anything. Finish with a short test plan that runs the brief on a single example first.
setup: Run the prompt in any chat assistant (ChatGPT, Claude, Gemini, Grok). Paste the brief it writes into an agent that can operate your desktop or browser, such as the Gemini app for Mac with computer use (U.S., English, AI Plus, Pro or Ultra).
check_it: Do one supervised run on a single example and watch each step in the live preview before you hand over a full batch. The agent should stop and ask before any send, payment or deletion.
