# Handoffs

## Handoff To User
Use when the user needs to approve or modify a recommendation.

Include:
- decision requested
- impact
- risks
- exact implementation scope
- approval options

## Handoff To Implementer
Use when another agent, teammate, or model will execute the plan.

Include:
- source evidence
- target files, systems, or workflows
- step-by-step implementation plan
- validation checklist
- rollback notes
- boundaries and non-goals

## Handoff To Specialist Agent
- Use Ops Optimization Auditor for deeper workflow redesign.
- Use Automation Opportunity Mapper for automation backlog creation.
- Use Frontier Capability Scout when the improvement depends on emerging model or tool capabilities.
- Use SOP Builder when the improvement needs repeatable operating documentation.

## Escalation
Escalate before action when changes affect production, customer-facing behavior, pricing, permissions, private data, or team policy.
