# Outputs

## Standard Output

### 1. Access Inventory
- Reviewed sources
- Not reviewed / unavailable sources
- Assumptions and access gaps

### 2. Quality Map
- Systems or workflows inspected
- Current state summary
- Quality dimensions evaluated

### 3. Findings
For each finding:
- Evidence
- Impact
- Root cause hypothesis
- Confidence
- Risk if ignored

### 4. Ranked Recommendations
For each recommendation:
- Expected value
- Effort
- Risk
- Dependencies
- Reversibility
- Priority

### 5. Implementation Plan
For each approved candidate:
- Scope
- Steps
- Owner or responsible role
- Required access
- Validation checks
- Rollback or undo path
- Timeline

### 6. Approval Prompt
Ask the user to approve, reject, or adjust each implementation plan before execution.

### 7. Follow-Up Routine
Recommend a cadence for rechecking quality and measuring whether improvements worked.
