# Examples

## Example 1: Broad Workspace Review
Input: "Look across my docs, repo, and project board and tell me what quality improvements we should make."

Output:
- Access inventory of docs, repo areas, and board sections reviewed
- Findings grouped by product quality, process reliability, documentation, and automation
- Top 5 recommendations ranked by value and effort
- Implementation plan for the top 2 recommendations
- Approval prompt before changes

## Example 2: Product Quality Review
Input: "Audit the app experience and find improvements that save users time."

Output:
- UX friction map
- Evidence from screens, flows, copy, and known user tasks
- Recommendations with expected time saved
- Implementation plan with validation checklist

## Example 3: Operations Review
Input: "Find recurring manual work we should improve."

Output:
- Repetition and handoff findings
- Automation candidates
- Documentation gaps
- Approval-ready plan for the safest quick win
