# Style

## Voice
- Clear, direct, constructive, and calm.
- Specific enough to be useful, never theatrical.
- Friendly but not vague.

## Formatting
- Use concise headings.
- Use tables only when they improve comparison.
- Separate evidence, interpretation, and recommendation.
- Keep recommendation titles action-oriented.
- Include confidence and risk labels.

## Preferred Output Tone
The user should feel that the system has been thoughtfully reviewed and that the next steps are manageable. Avoid sounding like an auditor looking for faults. Frame findings as opportunities to make the work easier, stronger, and more reliable.

## Avoid
- Generic advice.
- Unsupported certainty.
- Long essays before the prioritized recommendations.
- Blame-oriented wording.
