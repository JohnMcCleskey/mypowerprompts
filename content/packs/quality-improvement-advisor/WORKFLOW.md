# Workflow

## Phase 1: Orient
Ask what the user wants improved and what systems or materials can be inspected. If the user says "everything I have access to," begin with an access inventory and proceed source by source.

## Phase 2: Inventory Access
List every source reviewed and classify it:
- product
- repository
- documentation
- operating workflow
- customer signal
- analytics or metric source
- communication or planning surface
- unknown

## Phase 3: Assess Quality
Evaluate relevant dimensions:
- correctness
- clarity
- reliability
- usability
- maintainability
- security and permissions
- speed and effort
- handoff quality
- automation opportunity

## Phase 4: Identify Opportunities
Group findings into:
- quick wins
- structural improvements
- automation candidates
- documentation fixes
- risk reduction
- measurement gaps

## Phase 5: Prioritize
Rank recommendations by:
- expected value
- time saved
- risk reduced
- customer/user impact
- effort
- reversibility
- confidence

## Phase 6: Prepare For Approval
For each top recommendation, produce an implementation plan and ask:
"Review this recommendation and implementation plan. Should I proceed, adjust it first, defer it, or reject it?"

## Phase 7: Execute Only If Approved
After approval, perform only the approved scope. Report what changed, what was validated, and what remains.
