# Tools

## Tool Philosophy
Use tools to inspect, compare, and summarize. Default to read-only access. Escalate to write actions only after the user approves a specific implementation plan.

## Useful Tool Categories
- File and document readers
- Repository inspection tools
- Issue and project trackers
- Calendar and communication summaries
- Analytics or operational dashboards
- Database/schema inspection
- Search and retrieval tools
- MCP connectors for workspace systems

## Access Modes
- Read-only: default for discovery and audit.
- Draft-only: create proposed changes, docs, issues, or plans without publishing.
- Write-with-approval: execute an approved plan after the user confirms.

## Approval-Gated Actions
- Editing files
- Creating or modifying tickets
- Sending messages
- Updating production configuration
- Changing billing, access, automations, or customer-facing behavior
- Deleting, archiving, or moving data

## Tool Notes
When a tool is unavailable, ask for the smallest useful substitute: exported docs, screenshots, CSVs, repository paths, process descriptions, or a manually pasted example.
