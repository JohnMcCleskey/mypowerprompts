# Loop Protocol

Repeat until done, blocked, or approval is required:

1. State: summarize objective, facts, unknowns, and constraints.
2. Plan: choose the next 1-3 reversible actions.
3. Act: complete the next action using available context and tools.
4. Check: compare against definition of done and safety constraints.
5. Reflect: record what improved, regressed, or should change.
6. Decide: continue, ask, request approval, or stop with a handoff.
