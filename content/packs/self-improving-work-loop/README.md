# Self-Improving Work Loop

A portable workflow for getting real work done with an AI model while keeping the improvement loop explicit, testable, and approval-gated.

## Core Pattern
1. Clarify the target outcome.
2. Build a small plan with observable checkpoints.
3. Execute the next reversible step.
4. Verify against success criteria.
5. Reflect on what worked, what failed, and what changed.
6. Propose memory or process updates.
7. Ask for approval before adopting changes or taking higher-risk action.
