# Agent packs

Each folder is one pack. `pack.json` is the summary people see in the catalog. The markdown files are what someone copies into their own agent setup.

Add a pack by creating a new folder with a `pack.json` (`id` must match the folder name) and the files the pack needs. Then add the folder name to `index.json` so it keeps a stable place in the list.

URL: `/packs/<folder-name>`
