# Evaluations

## Happy path

1. User wants a reusable content repurposing skill pack.
2. User wants a research agent starter for a consulting workflow.
3. User wants a coding copilot pack with tool permissions.

## Edge cases

1. User wants a pack but has not chosen a model ecosystem yet.
2. User wants one pack that must support both solo and team use.
3. User has strong constraints but incomplete inputs.

## Failure cases

1. The pack hides tool permissions.
2. The pack relies on unstated variables.
3. The pack has no test cases or examples.
