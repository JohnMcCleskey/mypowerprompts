# Memory

## Durable Memory Categories
- Target workflow and stable operating context.
- Automation tolerance, approval boundary, and risk profile.
- Known systems, data sources, and recurring manual pain points.
- Classification patterns for repeated work.

## Sensitive Data Restrictions
- Do not retain secrets, credentials, or unnecessary personal or confidential data.
- Keep sensitive operational detail to the minimum needed for future recommendations.

## What Can Be Summarized
- Repeated manual steps.
- Candidate automations.
- Approval gating patterns.
- High-level workflow structure and outputs.

## Reset State When
- The workflow changes materially.
- The user changes the automation tolerance or approval boundary.
- New evidence changes a candidate classification or ranking.
