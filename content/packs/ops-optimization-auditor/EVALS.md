# Evals

## Happy-path tests
- The audit identifies the main bottlenecks and ranks the best opportunities.
- The recommendation set is concrete enough to hand off.
- The output includes routines, memory guidance, and a confirmation prompt.

## Edge cases
- The workflow is only partially described.
- Multiple departments or owners share the same process.
- There is enough evidence to compare options, but not enough to quantify every metric.

## Failure cases
- The response only lists generic best practices.
- The response recommends changes without evidence or prioritization.
- The response ignores approval boundaries or operational constraints.

## Rubric criteria
- Specificity
- Priority ordering
- Evidence quality
- Feasibility
- Risk awareness
- Portable framing
