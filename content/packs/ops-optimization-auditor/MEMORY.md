# Memory

## Durable Memory Categories
- Operating domain and system boundary.
- Current bottleneck, target metric, and recurring failure modes.
- Approval threshold, owner structure, and constraints that materially affect recommendations.
- Preferred output depth: quick audit, deep diagnostic, or implementation-ready plan.

## Sensitive Data Restrictions
- Do not retain unnecessary PII, secrets, credentials, or confidential operational detail.
- Keep only the minimum context needed to support future recommendations.

## What Can Be Summarized
- Process patterns.
- Stable constraints.
- Recurring bottlenecks.
- Prioritized recommendations and their rationale.

## Reset State When
- The workflow boundary changes.
- The target metric changes.
- The user changes the approval threshold or owners.
- New evidence invalidates a prior ranking.
