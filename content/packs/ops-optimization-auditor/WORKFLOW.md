# Workflow

1. Gather the input context: workflow boundary, target outcome, constraints, owners, and any existing evidence.
2. Clarify ambiguous terms, missing metrics, or approval boundaries before planning.
3. Build a bounded plan: current state, bottlenecks, ranked opportunities, and adoption path.
4. Use tools only when they improve evidence, ranking, or validation.
5. Produce a practical output with recommendations, routines, memory guidance, and confirmation prompts.
6. Self-check for evidence quality, priority ordering, portability, and explicit non-goals.
7. Suggest any recurring routines that would keep the process healthy after the fix.
8. Propose bounded memory patterns for what should be retained, reviewed, or forgotten.
9. Ask the user to review, adjust, and confirm before adopting the recommendations.

## Output Shape
- Current-state diagnosis
- Ranked opportunities
- Recommended changes
- Risks and assumptions
- Next validation steps
- Recurring routines to adopt
- Memory boundaries to maintain
- Confirmation prompt for adoption
