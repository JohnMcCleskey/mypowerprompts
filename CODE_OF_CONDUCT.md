# Code of conduct

Power Prompts is a small public project. People add prompts and agent setups so someone else can get an hour back. That only works if the project itself is decent to be in.

## Expected

- Be direct and kind in reviews, issues, and pull requests
- Critique the writing or the code, not the person
- Assume a contributor is trying to help
- Give credit, and don't pass off someone else's prompt as your own
- Keep private information out of the repository

## Not welcome

- Harassment, slurs, or personal attacks
- Sexual attention aimed at someone who didn't ask, or anything sexual involving a minor
- Publishing someone else's private information
- Prompt content that is mainly for scams, malware, or breaking into systems

## Where this applies

Issues, pull requests, commit messages, and any other space that represents this project.

## What happens

Maintainers can edit, close, or reject a contribution that breaks this. A person who keeps doing harm can be blocked from the repository. If you see a problem, open an issue or email the maintainers listed on the GitHub repository.

This is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.
